# Haven Word Church Website

## Overview
The Haven Word Church website was created to provide an online presence for the church and make it easier for members and visitors to access important information about services, events, and church activities.

The goal of this project was to create a simple, welcoming, and responsive website that reflects the church's community and mission.

## Features
- Responsive design for all devices
- Information about church services and events
- Sections for ministry updates and announcements
- Clean and accessible navigation
- User-friendly layout for visitors

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## My Role
- Designed and developed the website layout
- Implemented responsive design
- Organized church content for easy access
- Ensured the website is accessible and user-friendly
